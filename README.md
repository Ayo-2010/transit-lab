# Transit Lab

A live metro network control room with an interactive map, shortest-path journey planning and simulated trains. Built with plain HTML, CSS and JavaScript.

**Live demo:** https://ayo-2010.github.io/transit-lab/

## Features

- Four-line, fourteen-station SVG metro map with hover labels and keyboard-selectable stations
- Click a station to set an origin, then a destination, or use the journey planner selects
- Dijkstra route finding with travel time, line changes and a fare estimate
- Turn individual lines off to see how the network and routes respond
- Live departure board, service alerts and eight moving trains
- Station tooltips, line legend and a running local clock
- Responsive layout down to 390px, reduced motion support and a global `[hidden]` rule

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
